## Сравнение методов

| Метод и задача | Что получилось на тесте | Особенности |
| --- | --- | --- |
| **Линейная регрессия** — прогноз медианной стоимости жилья в районе | Доход жителей дал R² = 0,478. С координатами результат вырос до 0,594, а со всеми восемью признаками — до 0,650. Число комнат на домохозяйство почти ничего не добавило. | Прогноз считается как взвешенная сумма признаков. В этой модели встречались отрицательные прогнозы цены. |
| **k ближайших соседей** — определение класса вина по химическим измерениям | Фиксированный набор признаков дал 35 верных ответов из 36 при всех трёх проверенных значениях k. Со случайным набором верных ответов было от 29 до 30. | Класс определяют голоса ближайших образцов. Чтобы один столбец не перевешивал остальные из-за единиц измерения, признаки стандартизируются. Соседей приходится искать при каждом прогнозе. |
| **Небинарное дерево решений** — разделение грибов на съедобные и ядовитые | При пороге 50% дерево нашло 778 из 783 ядовитых грибов без ложных тревог. При пороге около 5,27% нашло все 783, а ещё 133 съедобных пометило как ядовитые. | Решение можно проследить по вопросам дерева. В корне было девять ветвей — по одной на каждый вариант запаха. |
| **Логистическая регрессия** — прогноз результата проверки на диабет | Модель, обученная методом Ньютона с шагом 0,1 за 10 итераций, дала 117 верных ответов из 154. Из 54 положительных случаев она нашла 32. F1 составила 0,634. | Модель выдаёт оценку вероятности. По порогу из неё получают класс. Граница между классами линейная. |

## Общий вывод

Для прогноза цены заметно помогли координаты, а в задаче про вино выбор признаков повлиял на результат сильнее, чем выбор между k = 3, 5 и 10. В задачах классификации важен и характер ошибок. На грибах снижение порога убрало пропуски ценой ложных тревог, а в задаче про диабет при 76% верных ответов модель пропустила 22 положительных случая.

В опыте с логистической регрессией при шаге 1 Ньютон сделал 5 обновлений, а градиентный спуск — 200. К концу обоих запусков ошибка на обучении была около 0,474. Шаг Ньютона требует решения системы уравнений, поэтому для сравнения времени работы нужен отдельный замер.

Значение k и настройки логистической регрессии я выбрал на валидационной выборке. Тестовую выборку использовал для итоговой проверки.
